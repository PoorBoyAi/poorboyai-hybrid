# Ask PB — PoorBoyAI on the web, answered on your device

**Ask PB** is PoorBoyAI's AI companion answering questions on the web for the
first time — and, in Chrome on desktop, the answer is generated by **Gemini
Nano on the visitor's own machine** through Firebase AI Logic hybrid
inference. Everywhere else, the same question falls back to a cloud-hosted
Gemini model. A badge on every answer shows which lane served it, read from
the SDK's own `inferenceSource` report — never guessed.

Built by [PoorBoyAI](https://poorboyai.com) for Google's **#BuildHybridAI**
hackathon (Firebase AI Logic hybrid inference, Web / Chrome).

## Why hybrid, why this shape

PB lives in PoorBoyAI's Telegram community, answering members all day. This
project gives PB a public web front door — and hybrid inference is exactly
the right tool for it:

- **Private** — on-device answers mean the question never leaves the machine.
- **Free** — on-device inference costs nothing, at any scale.
- **Offline-capable** — Nano answers with no connection at all.
- **Reachable** — the cloud lane answers for everyone else, same PB voice,
  same fact sheet, same single SDK call.

On-device inference in the Firebase web SDK is single-turn text generation
(no chat sessions) — so Ask PB is deliberately shaped as one question, one
answer. It fits the limit instead of fighting it.

## How it works

- `src/ask.ts` — the whole hybrid call. `getAI(app, { backend: new
  GoogleAIBackend() })`, then `getGenerativeModel(ai, { mode:
  InferenceMode.PREFER_ON_DEVICE, onDeviceParams, inCloudParams })`, answered
  with `generateContentStream` so the answer types out live.
- Before the call, `LanguageModel.availability()` (Chrome Prompt API) drives
  the "checking on-device…" state; `model.initializeDeviceModel()` runs
  inside the Ask button's user gesture, as the Prompt API requires.
- The lane badge is set from `response.inferenceSource` (`on_device` /
  `in_cloud`, Firebase JS SDK v12.5.0+). If a response ever arrives without
  it, the badge falls back to the availability result and is labeled
  "(inferred)".
- `src/facts.ts` — PB's voice + a compact PoorBoyAI fact sheet, fed to both
  lanes as the system prompt (Prompt API `initialPrompts` on-device,
  `systemInstruction` in the cloud), sized for Nano's small context window.
- `src/firebase.ts` — Firebase init + **App Check** with the reCAPTCHA v3
  provider (debug-token flow on localhost). AI Logic is enforced by App
  Check, as the hackathon requires.
- Cloud fallback model: `gemini-3.5-flash-lite`, the Firebase AI Logic
  default for SDK v13, named explicitly so the cloud lane can carry PB's
  system instruction.

## Run it locally

```bash
npm install
cp .env.example .env   # fill in your Firebase project config (below)
npm run dev
```

### Firebase setup (one-time, ~10 minutes)

1. Create a Firebase project at
   [console.firebase.google.com](https://console.firebase.google.com)
   (Spark / no-cost plan is fine; Google Analytics not needed).
2. In the console: **AI Services → AI Logic → Get started**, and choose the
   **Gemini Developer API** provider. This enables the required APIs and
   turns on App Check enforcement for AI Logic.
3. Register a **Web app** in Project settings and copy its config into
   `.env` (see `.env.example`).
4. App Check: create a **reCAPTCHA Enterprise** site key in the Google Cloud
   console for your hosting domain + `localhost`, register it under
   **App Check → Apps → your web app** (Fraud Defense / reCAPTCHA Enterprise
   provider — the Classic v3 provider is deprecated), and put the site key
   in `.env` as `VITE_RECAPTCHA_ENTERPRISE_SITE_KEY`.
5. For local dev, load the page once on localhost, copy the App Check debug
   token from the browser console, and safelist it under **App Check → Apps
   → Manage debug tokens**.

On-device answers additionally need Chrome 139+ on desktop with
`chrome://flags/#prompt-api-for-gemini-nano-multimodal-input` enabled; the
first availability check may trigger the Gemini Nano model download.

### Deploy

```bash
npm run build
npx firebase-tools deploy --only hosting   # firebase.json is included
```

## Tech

Vite + vanilla TypeScript (no framework weight), Firebase JS SDK v13
(`firebase/app`, `firebase/ai`, `firebase/app-check`). That's the whole
stack — everything else is ours.
